# Chapter 3. Learning SQL Group (Aggregate) Functions

## Overview
This chapter covers SQL group (aggregate) functions, which process multiple rows and return a single summary value for each group.  
It focuses on summarizing, analyzing, and reporting data in Oracle SQL using aggregation and grouping techniques.

## Key Topics Covered
- **Concept of Group (Aggregate) Functions:**  
  Understand how aggregate functions operate on sets of rows and how they are commonly used with `GROUP BY` and `HAVING` clauses.

- **Core Aggregate Functions:**  
  Learn the usage of `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`, as well as statistical functions such as `STDDEV` and `VARIANCE`.

- **Grouping and Filtering:**  
  Apply `GROUP BY` to organize data into groups and use `HAVING` to filter groups based on aggregate results.

- **Advanced Grouping Features:**  
  Work with `ROLLUP`, `CUBE`, `GROUPING SETS`, and `LISTAGG` to generate subtotals, grand totals, and flexible summary reports.

- **Data Transformation and Reporting:**  
  Use `PIVOT` and `UNPIVOT` to reshape result sets for cross-tab and reporting purposes.

- **Analytical and Ranking Functions:**  
  Explore functions such as `LAG`, `LEAD`, `RANK`, `DENSE_RANK`, `ROW_NUMBER`, and window-based aggregations using `SUM() OVER`.

## Purpose
This chapter is intended to help learners analyze grouped data and produce meaningful summaries using Oracle SQL.  
By mastering group and aggregate functions, readers can create accurate reports and perform advanced data analysis.

# Chapter 3. SQL 그룹(집계) 함수 학습

## 개요
이 장은 Oracle SQL의 그룹(집계) 함수에 대한 개념 정리로 구성됨.  
여러 행을 대상으로 하나의 요약 값을 반환하는 함수의 특성과 데이터 요약 및 분석에의 활용 방식 소개를 포함함.

## 주요 학습 주제
- **그룹(집계) 함수 개념:**  
  다중 행 집합을 대상으로 동작하는 집계 함수의 특성과 `GROUP BY`, `HAVING` 절과의 관계에 대한 이해.

- **기본 집계 함수:**  
  `COUNT`, `SUM`, `AVG`, `MAX`, `MIN` 함수와 함께 `STDDEV`, `VARIANCE` 등 통계 함수의 사용 방법 학습.

- **그룹화 및 필터링:**  
  `GROUP BY` 절을 이용한 데이터 그룹화 방식과 `HAVING` 절을 활용한 집계 결과 기반 필터링 구조 정리.

- **고급 그룹화 기능:**  
  `ROLLUP`, `CUBE`, `GROUPING SETS`, `LISTAGG`를 활용한 소계·총계 계산 및 유연한 요약 리포트 구성 방식 학습.

- **데이터 형태 변환 및 리포팅:**  
  `PIVOT`, `UNPIVOT`을 활용한 행·열 전환 및 교차 집계 결과 생성 방식 정리.

- **분석 및 순위 함수:**  
  `LAG`, `LEAD`, `RANK`, `DENSE_RANK`, `ROW_NUMBER`, `SUM() OVER` 등 분석 함수의 활용 구조 이해.

## 목적
이 장은 그룹 단위 데이터에 대한 집계 및 분석 방식 이해를 목표로 구성됨.  
이를 통해 요약 리포트 작성과 고급 데이터 분석에 필요한 SQL 활용 역량 확보를 목적으로 함.
