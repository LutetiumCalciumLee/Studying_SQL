# Chapter 2. Learning SQL Single-Row Functions

## Overview
This chapter introduces Oracle SQL single-row functions, which process data on a row-by-row basis and return a single value for each row.  
It focuses on using built-in functions to manipulate, format, and transform data directly within SQL queries.

## Key Topics Covered
- **Concept of Single-Row Functions:**  
  Understand how single-row functions operate on individual rows and how they can be applied in clauses such as `SELECT`, `WHERE`, and `ORDER BY`.

- **Character Functions:**  
  Learn functions for string manipulation, including case conversion, length calculation, substring extraction, padding, trimming, replacement, and regular expression-based processing.

- **Number Functions:**  
  Use numeric functions to perform calculations, rounding, truncation, and mathematical operations on numeric data.

- **Date Functions:**  
  Work with date and time values using functions for date calculation, formatting, and adjustment.

- **Conversion and General Functions:**  
  Convert data between different types and handle null values or conditional logic using conversion and general-purpose functions.

## Purpose
This chapter is intended to help learners effectively use single-row functions to process and format data within SQL statements.  
By mastering these functions, readers can write more expressive and efficient queries for data transformation and analysis.

# Chapter 2. SQL 단일 행 함수 학습

## 개요
이 장은 Oracle SQL의 단일 행 함수에 대한 기본 개념 설명으로 구성됨.  
각 행마다 하나의 값을 반환하는 함수의 특성과 SQL 문 내에서 데이터 처리 및 형식 변환에 활용하는 방법 소개를 포함함.

## 주요 학습 주제
- **단일 행 함수 개념:**  
  단일 행 함수의 동작 방식과 `SELECT`, `WHERE`, `ORDER BY` 절 등에서의 활용 구조 이해.

- **문자 함수:**  
  대소문자 변환, 길이 계산, 부분 문자열 추출, 패딩, 공백 제거, 문자열 치환, 정규 표현식 기반 문자열 처리 함수 학습.

- **숫자 함수:**  
  반올림, 버림, 나머지 계산 등 숫자 데이터에 대한 연산 및 수학적 처리 함수 활용 방식 정리.

- **날짜 함수:**  
  날짜 계산, 형식 변환, 기준 날짜 조정 등 날짜 데이터 처리 함수 학습.

- **형변환 및 일반 함수:**  
  데이터 타입 변환 함수와 NULL 처리 및 조건 분기 로직 구현을 위한 일반 함수 활용 방법 정리.

## 목적
이 장은 SQL 문 내에서 단일 행 함수를 활용한 데이터 가공 및 표현 방식에 대한 이해를 목표로 구성됨.  
이를 통해 데이터 변환, 정제, 분석에 필요한 쿼리 작성 역량 확보를 목적으로 함.
