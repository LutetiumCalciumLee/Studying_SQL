# Chapter 1. Querying Data with SELECT

## Overview
This chapter introduces the fundamentals of retrieving data from an Oracle database using the `SELECT` statement.  
It focuses on essential syntax, query structure, and commonly used clauses for filtering, sorting, and organizing query results.

## Key Topics Covered
- **SELECT Statement Basics:**  
  Understand the purpose and structure of the `SELECT` statement, including the SELECT list and the FROM clause, used to retrieve data from tables and views.

- **Selecting Columns and Expressions:**  
  Learn how to select all columns or specific columns, use column aliases, combine columns with literals, and remove duplicate results using `DISTINCT`.

- **Filtering and Sorting Data:**  
  Use the `WHERE` clause to filter rows with comparison, logical, and pattern-matching operators, and apply the `ORDER BY` clause to sort query results.

- **Set Operators:**  
  Work with `UNION`, `UNION ALL`, `INTERSECT`, and `MINUS` to combine or compare results from multiple queries.

- **User Input and Basic Calculations:**  
  Use substitution variables for user input and apply arithmetic expressions and aggregate functions to perform basic calculations.

## Purpose
This chapter is designed to help learners build a clear understanding of how data is queried in Oracle SQL.  
By practicing these concepts, readers can write accurate and readable queries that serve as the foundation for more advanced SQL operations.

# Chapter 1. SELECT 문을 이용한 데이터 조회

## 개요
이 장은 Oracle 데이터베이스에서 `SELECT` 문을 사용하여 데이터를 조회하는 기본 개념에 대한 설명으로 구성됨.  
쿼리의 기본 구조와 데이터 필터링, 정렬, 결과 구성에 필요한 주요 문법 소개를 포함함.

## 주요 학습 주제
- **SELECT 문 기초:**  
  테이블이나 뷰에서 데이터를 조회하기 위한 `SELECT` 문의 역할과 기본 구조(SELECT 절과 FROM 절)에 대한 이해.

- **컬럼 선택 및 표현식:**  
  전체 컬럼 또는 특정 컬럼 선택 방법, 컬럼 별칭 사용, 리터럴과 컬럼 결합 방식, `DISTINCT`를 통한 중복 제거 방법 학습.

- **데이터 필터링 및 정렬:**  
  `WHERE` 절을 활용한 조건 필터링과 비교·논리·패턴 연산자 사용 방식, `ORDER BY` 절을 이용한 결과 정렬 방법 정리.

- **집합 연산자:**  
  `UNION`, `UNION ALL`, `INTERSECT`, `MINUS`를 활용한 다중 쿼리 결과 결합 및 비교 방식 학습.

- **사용자 입력 및 기본 계산:**  
  치환 변수(substitution variable)를 활용한 사용자 입력 처리 방식과 산술 표현식 및 집계 함수를 이용한 기본 계산 방법 정리.

## 목적
이 장은 Oracle SQL에서 데이터 조회의 기본 흐름에 대한 이해를 목표로 구성됨.  
이후 조인, 함수, 서브쿼리 학습에 필요한 기초 쿼리 작성 역량 확보를 목적으로 함.
